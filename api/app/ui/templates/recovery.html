{% if figures.diverges %}
The two figures differ, and that is expected. Time-window counts money that arrived during the run for any reason; causal counts only invoices the run actually acted on and the gate approved.

Neither figure bounds the other. Time-window runs ahead when money arrives mid-run for reasons that have nothing to do with the run — including invoices where the gate refused to make contact and the counterparty paid anyway, which is money this screen never claims. Causal runs ahead when a run finishes in seconds and the payments it caused land hours later, which leaves time-window counting almost nothing. Causal is the headline either way, because it is the only one of the two that can name the invoices it counted — the same argument the audit log makes, expressed as a number.
